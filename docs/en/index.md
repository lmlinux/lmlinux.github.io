# lmlinux

**Linux with a local language model built in, available fully offline.**

[Explore lmlinux](lmlinux/index.md){ .md-button .md-button--primary }
[中文](../index.md){ .md-button }

lmlinux integrates a local assistant into Debian 13.8.0 live Cinnamon for offline rescue and for first installation and first boot without a network. The current release is `13.8.0-rc1`, a release candidate.
